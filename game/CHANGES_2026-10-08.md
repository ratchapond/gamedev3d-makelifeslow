# รุ่นแก้ไข 8 ตุลาคม 2026

- พื้นที่วางวัตถุใช้ความสูงจากสามเหลี่ยมเดียวกับ mesh การชน ม้านั่งและ NPC ตามระดับพื้น
- ถนนเป็นพื้นผิวต่อเนื่องตามภูมิประเทศ ลำธารมีตลิ่งสองฝั่งและร่องบนพื้นจริง สะพานมีการชนและทางลาด
- ปิดหน้าจั่วบ้านทั้งด้านหน้าและด้านหลังให้ตรงกับมุมหลังคา
- หมาและแมวโตขึ้น และเดินตามคนละจุดพร้อมหลบกัน
- รถกระบะทรงมนเพิ่มกระจก กระบะท้าย กระจกมองข้าง กันชน ไฟและล้อ ปรับแนวตัวรถตามความลาดพื้น
- UI กระจกโปร่ง มีการเบลอเบื้องหลัง ขอบและเงา โดยภาพต่ำปิดการเบลอ
- จอยเลือกเมนู ซื้อของ ปรับ slider/คุณภาพภาพและจำนวนขายได้ เลื่อนรายการตามโฟกัสอัตโนมัติ
- ภาพต่ำแบบความละเอียดอัตโนมัติบนเว็บใช้เป้าหมาย 960×540 ภาพสูงใช้ 1280×720 ส่วน UI คงความละเอียดเต็มจอ

การตรวจสอบ: system tests 25 รายการ และ integration tests 49 รายการผ่าน
การเทียบที่กล้อง เวลา และความละเอียด 3D เดียวกันในเว็บของ Codex (Intel UHD):
ภาพสูง 24.5 / 23.8 FPS, ภาพต่ำ 27.3 / 24.7 FPS ในสองรอบ จึงยังไม่พบอาการภาพต่ำช้ากว่าภาพสูงในฉากทดสอบ
ผลนี้ไม่ได้แทนประสิทธิภาพของทุกฉาก ทุก browser หรือคอมของผู้เล่น
