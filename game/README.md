# Make Life Slower — Alpine Farm

เดโมเกมฟาร์ม 3D เล่นคนเดียว สร้างและทดสอบด้วย Godot 4.7.2, GDScript และ Compatibility renderer สำหรับเว็บคอม

## เริ่มเล่น

- Windows: เปิด `build/windows/MakeLifeSlower.exe` ได้เลย
- เว็บบนเครื่องนี้: เปิด `Play_Web.cmd` แล้วไปที่ http://127.0.0.1:8765/ เซิร์ฟเวอร์เปิดเฉพาะเครื่องนี้
- แก้เกมบนเครื่องนี้: เปิด `Open_Editor.cmd` หรือเปิด `project.godot` ด้วย Godot 4.7.2 แล้วกด F6/F5 ตามฉากที่ต้องการ ตัวเอนจินแบบพกพาอยู่ใน `../tools/godot/`

เริ่มใหม่มีเงิน 550 เมล็ดแครอต/มะเขือเทศ/ฟักทอง อาหารสัตว์ 8 ถุง ไก่วัยเด็ก 1 ตัว และลูกวัว 1 ตัว

## การควบคุม

| ปุ่ม | การใช้งาน |
|---|---|
| WASD / เมาส์ | เดิน / มองรอบตัว |
| ลูกศร | มองรอบตัวสำรอง หากเบราว์เซอร์มีปัญหา pointer lock |
| L | เปิด / ปิดตะเกียงตอนกลางคืน |
| Shift | วิ่ง |
| V | สลับ FPS/TPS |
| 1–4 / ลูกกลิ้ง | จอบ บัวรดน้ำ เมล็ด ตะกร้า |
| คลิกซ้าย / E | ใช้เครื่องมือกับแปลง / โต้ตอบ |
| I | กระเป๋าและเลือกเมล็ด |
| M | แผนที่และตั้งจุดนำทาง |
| Esc | พัก / ตั้งค่า |
| F5 | บันทึก (ใช้เมนูบันทึกในเว็บได้เช่นกัน) |

แปลงอยู่เหนือบ้าน คอกสัตว์อยู่ทางตะวันออก เข้าคอกผ่านช่องประตูด้านตะวันตก ร้านค้าอยู่ตามถนนไปทางตะวันออกเฉียงเหนือ เตียงอยู่ในบ้าน ขึ้น/ลงรถด้วย E แล้วใช้ W/S ขับ A/D เลี้ยว

## ระบบที่เล่นได้

- เตรียมดิน ปลูก รดน้ำ เติบโตตามวัน เก็บเกี่ยวพืช 3 ชนิด พืชไม่รดน้ำจะหยุดโต
- ปศุสัตว์ 6 ชนิด: ไก่ เป็ด วัว แพะ แกะ หมู และเพื่อนสุนัข/แมว
- ทุกชนิดมีวัยเด็กและเต็มวัย ไฟล์เกมมีโครงกระดูกและท่ายืน/เดิน/กิน ส่วนคนมีท่าใช้เครื่องมือ
- ให้อาหาร เก็บไข่/นม/ขน ซื้อสายพันธุ์พิเศษ ขายสัตว์ทั้งตัว หรือส่งสัตว์โตไปแปรรูปเป็นเนื้อผ่านเมนู
- ตลาดเลือกชนิดและจำนวนผลผลิตที่จะขาย พร้อมยอดเงินก่อนยืนยัน ร้านเมล็ด ร้านสัตว์/อาหาร และร้านช่าง
- อัปเกรดแปลง 12 → 24 → 36 เครื่องมือ บ้าน/พื้นที่กระเป๋า และคอกสัตว์
- กลางวัน/กลางคืน นอนข้ามวัน ฤดูกาลทุก 7 วัน ฤดูหนาวพืชโตช้าลง
- เป้าหมายในสมุดชาวสวนให้รางวัลเพิ่มเติม ไม่มี Game Over
- เซฟอัตโนมัติหลังทำรายการ ทุกประมาณ 35 วินาที และเมื่อนอน เซฟตำแหน่งคน/รถด้วย
- ตั้งค่าเสียงหลัก เพลง เอฟเฟกต์ ธรรมชาติ ความไวเมาส์ กลับแกน FOV เงา เต็มจอ และจำกัด/แสดง FPS
- เพลงและเสียงสังเคราะห์ต้นฉบับสำหรับเดโม

พื้นที่เดินประมาณ 280 × 280 เมตร มีบ้านไม้ หมู่บ้าน ป่าไม้ใบกว้างเป็นโซน ลำธาร ทะเลสาบและภูเขาหิมะไกล ๆ ฉากส่วนใหญ่สร้างจากโค้ด ต้นไม้ ดอกไม้ และพืชใช้ MultiMesh; พื้นหญ้าเรียบและแปลงขอบมนวาดรวมตามวัสดุ เพื่อลดจำนวนคำสั่งวาด โมเดลเกมเป็นสำเนาที่ลดความละเอียดจากต้นฉบับ

## รอบปรับภาพและการควบคุม

- เมาส์หันกล้องตามการเคลื่อนที่โดยไม่ต้องกดขวาค้าง มีจุดกลางจอ; Esc ปล่อยเมาส์และพักเกม ในเบราว์เซอร์ที่ปฏิเสธ pointer lock ใช้การขยับเมาส์ภายในหน้าจอหรือลูกศรสำรอง
- Xbox: ก้านซ้ายเดิน ก้านขวามอง A โต้ตอบ X/RT ใช้เครื่องมือ LB/RB สลับเครื่องมือ Y กระเป๋า View แผนที่ กดก้านขวา FPS/TPS กดก้านซ้ายวิ่ง D-pad ขึ้นสลับตะเกียง Start พัก B ปิดเมนู ระบบเปลี่ยนคำแนะนำปุ่มตามอุปกรณ์ล่าสุด; เมนูใช้ก้าน/D-pad และ A เลือก
- รถเร่งถึง 16 เมตร/วินาที (เดิน 3.2 วิ่ง 5.4) ถอยหลัง 7 มีการเร่งและผ่อนคันเร่ง
- ร้านมีภาพสัตว์ที่เรนเดอร์จากโมเดลจริง และภาพประกอบเมล็ด/ผลผลิต/อัปเกรด NPC ทักเมื่อเข้าใกล้และซ่อนข้อความเมื่อเดินออก
- พืชโตไว/ปานกลาง/ช้า ราคาต่างกัน ไม่แสดงตัวเลขวันของพืช; ดูสถานะโตและพร้อมเก็บแทน
- ภูเขาหิมะสองลูกอยู่ทางเหนือ ป่าเป็นกลุ่ม ลดต้นไม้ หญ้าเส้น และก้อนสีบนพื้น; ดอกไม้มีใบ ก้าน และกลีบ
- แปลงมีขอบมนและผิวดิน หน้าหลักมีลายต้นอ่อน เส้นทางไม่ตัดผ่านคอก ม้านั่งและที่จอดรถอยู่ข้างทาง
- กลางคืนมืดจริง มีดวงจันทร์ แสงหน้าต่างและตะเกียง; ดวงอาทิตย์แสดงบนท้องฟ้าตามเวลา
- รวมการวาดแปลง ลดรายละเอียด NPC ที่ไกล ปิดเงาพื้นดิน และจำกัดไฟกลางคืนให้อยู่ใกล้ผู้เล่นเพื่อช่วยการเล่นเว็บ

## อัปโหลด

`build/MakeLifeSlower_Web.zip` มี `index.html` อยู่ระดับราก อัปโหลดเป็นเกม HTML5 ใน itch.io เลือกให้เล่นในเบราว์เซอร์และเปิดเต็มจอได้ ขนาดแนะนำ 1280 × 720 เทมเพลตเว็บใช้เธรดเดียว ไม่ต้องตั้ง cross-origin isolation

GitHub Pages: นำเนื้อหาใน `build/web/` ไปไว้ในโฟลเดอร์ที่ Pages เผยแพร่ อย่าเปลี่ยนชื่อไฟล์ `index.*` อัปโหลดทั้งชุด ไฟล์เว็บต้องให้บริการผ่าน HTTP(S) การเปิด `index.html` แบบไฟล์ตรง ๆ จะไม่ทำงาน

เซฟเว็บเก็บในพื้นที่ของเบราว์เซอร์สำหรับเว็บไซต์นั้น เซฟ localhost, itch.io และ GitHub Pages เป็นคนละชุด การล้างข้อมูลเว็บไซต์จะลบเซฟด้วย

## ตรวจสอบและแก้ไข

โค้ดระบบอยู่ใน `scripts/farm.gd` ฉากใน `scripts/world.gd` ผู้เล่นใน `scripts/player.gd` และหน้าจอใน `scripts/ui.gd`

รันการทดสอบด้วย Godot CLI:

```
godot --headless --path . --script res://tests/systems.gd
godot --headless --path . --script res://tests/integration.gd
```

ทดสอบด้วยข้อมูลและไฟล์เซฟแยกจากการเล่นจริง การส่งออกจาก Godot Editor ให้ติดตั้ง export templates รุ่นเดียวกับเอนจินก่อน

เดโมมีริกและแอนิเมชันพื้นฐาน ยังไม่มี multiplayer/cloud save การขับรถเป็นแบบอาร์เคด และเสียงสัตว์เป็นเสียงสังเคราะห์ ควรทดสอบบนเครื่องและเบราว์เซอร์เป้าหมายก่อนเผยแพร่จริง
