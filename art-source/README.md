# Rigged game copies

20 separate Blender files: player, three merchants/craftsman, and young/adult copies of cow, chicken, duck, sheep, goat, pig, dog and cat.

These are reduced game meshes with armatures and NLA animation tracks. Humans: Idle, Walk, Use. Animals: Idle, Walk, Eat. Units: metres, 24 FPS. Matching exported GLB files are in `../MakeLifeSlower/assets/models/`.

The original appearance models in `../output/` are preserved. These game rigs use automatic region weights and provide basic prototype animation. More detailed secondary movement and polished production animation can be edited in these Blender files.
